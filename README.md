🌾 Missão Agro-Verde — Projeto Agrinho 2026
📝 Sobre o Projeto
O "Missão Agro-Verde" é um site interativo e educacional desenvolvido para o Concurso Agrinho 2026, cujo tema é "AGRO FORTE, FUTURO SUSTENTÁVEL: EQUILÍBRIO ENTRE PRODUÇÃO E MEIO AMBIENTE".

O projeto utiliza o conceito de gamificação e storytelling (narrativa interativa) para colocar o usuário no papel de um produtor rural. O objetivo principal é engajar o público jovem e demonstrar de forma prática que a lucratividade do agronegócio depende diretamente da preservação dos ecossistemas.

🚀 Funcionalidades do Site
O sistema funciona como uma aplicação de página única (Single Page Application), dividida em três seções principais:

1. 🎮 O Simulador (RPG Interativo)
É o núcleo do projeto, onde o usuário gerencia uma Fazenda Modelo através de tomada de decisões estratégicas baseadas em turnos.

Painel de Indicadores Dinâmicos: O site exibe em tempo real o Capital Atual (recursos financeiros), a Sustentabilidade (saúde ambiental através de uma barra de progresso colorida) e a Biodiversidade (status das abelhas).

Mecânica de Causa e Efeito (O Diferencial das Abelhas): Caso o jogador escolha soluções imediatistas e poluentes (como o uso excessivo de agrotóxicos), o sistema ativa o desaparecimento das abelhas. No turno seguinte, a ausência de polinizadores gera uma severa punição financeira, simulando a quebra real de safra por desequilíbrio ecológico.

Relatório Final: Ao término das rodadas, a inteligência do código calcula os resultados e emite um veredito sobre a gestão do jogador (Sucesso Sustentável, Produção Moderada ou Colapso Ecológico).

4. 🏆 Agrinho 2026
Uma página institucional que contextualiza as diretrizes do concurso e defende a tese do projeto: provar cientificamente e matematicamente, através do código, que o manejo consciente é o único caminho viável para um agro forte no futuro.

🛠️ Tecnologias Utilizadas
O projeto foi construído do zero, sem o uso de frameworks externos, garantindo a originalidade do código para a avaliação técnica do concurso:

HTML5: Criação da estrutura textual, seções e elementos da interface do simulador.

CSS3: Estilização visual moderna e responsiva, utilizando uma paleta de cores voltada à natureza, efeitos de transição suave (fade-in) e componentes visuais como barras de progresso.

JavaScript (Vanilla): Responsável por toda a lógica de alternância de páginas, armazenamento das variáveis de pontuação, motor de decisões do RPG e manipulação do DOM (alterações visuais de texto e cores conforme as escolhas do jogador).

🎯 Objetivo de Criação
Este site foi criado para provar que a educação ambiental não precisa ser rígida ou teórica. Ao "jogar" e sofrer as consequências econômicas da extinção das abelhas em sua própria fazenda virtual, o estudante compreende de forma imediata e lúdica a mensagem central do Agrinho 2026: não existe agro forte sem futuro sustentável.
